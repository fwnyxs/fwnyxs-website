# Traits Enterprise website

Standalone HTML/CSS/JavaScript website for Google Traits Melawati / Traits Enterprise.

## Structure

- `index.html` - main marketing website
- `assets/styles.css` - site theme and responsive layout
- `assets/app.js` - mobile navigation only
- `assets/brand-mark.svg` - local brand asset
- `cookies/` - privacy, disclaimer, and cookie pages

The site does not require Python, Node, or a build step. Open `index.html` directly or serve this folder with any static server.
